# Cześć, tu vx9forge

**Tworzę małe narzędzia na Windows i Androida. Uczę się, eksperymentuję i korzystam z pomocy AI.**

Nie buduję kolekcji modnych haseł. Wolę wziąć konkretny pomysł, uruchomić go i krok po kroku poprawiać.

## Mój warsztat

| Obszar | Nad czym pracuję |
| --- | --- |
| **Windows** | Narzędzia desktopowe i wygodny dostęp do codziennych funkcji. |
| **Android** | Aplikacje mobilne i praktyczne eksperymenty z interfejsem. |
| **AI i automatyzacja** | Wsparcie tworzenia, analiza problemów i usprawnianie powtarzalnej pracy. |

## Jak podchodzę do projektów

**Małe kroki, czytelne zmiany.** Pomysł → prototyp → testy → poprawki.

AI jest częścią mojego warsztatu, a nie zamiennikiem sprawdzania rezultatów. Zależy mi na użyteczności, prostocie i dokumentacji, do której można wrócić.

## Co znajdziesz na tym profilu

Większość pracy prowadzę w prywatnych repozytoriach. Ten profil jest moją wizytówką — bez ujawniania kodu i szczegółów prywatnych projektów.

Gdy pojawią się projekty gotowe do publicznego pokazania, znajdziesz je w przypiętych repozytoriach.
