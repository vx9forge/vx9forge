# Security Policy

This is the public **vx9forge** GitHub profile repository (README and assets). It does not ship application binaries.

## Reporting

For security issues in **public content on this repository**, use **Security → Advisories → Report a vulnerability** or contact the owner via GitHub.

For vulnerabilities in private H.W.D.P applications, report through the **Security** tab of the relevant private repository (suite access required).

## Scope

In scope: misleading or harmful content in this profile repo. Out of scope: private suite code not published here.
